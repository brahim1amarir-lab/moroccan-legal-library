# المكتبات القانونية المغربية

نصوص تشريعية وتنظيمية مغربية سارية إلى غاية نونبر 2026، محولة إلى Markdown ومفهرسة حسب المادة. أصلها ملفات PDF الرسمية (البوابة القانونية لوزارة العدل، الجريدة الرسمية، المديرية العامة للضرائب، وزارة النقل).

| الرمز | المكتبة | عدد النصوص الكاملة |
|---|---|---|
| `land` | العقار والوعاء العقاري | 63 |
| `tax` | الجبايات والضرائب | 26 |
| `crim` | القانون الجنائي والمسطرة الجنائية | 41 |
| `rent` | الكراء | 12 |
| `fam` | الأسرة والحالة المدنية | 16 |
| `civ` | المادة المدنية | 74 |
| `soc` | المادة الاجتماعية | 83 |
| `tr` | النقل الطرقي للأشخاص | 110 |

## البنية

- `<الرمز>/<الرقم>.md`: نص كامل، يبدأ برأس YAML فيه العنوان ورابط `source` إلى ملف PDF الرسمي. كل مادة عنوان مستقل: `##### المادة 304` أو `##### الفصل 230`.
- `catalog.json`: فهرس كل المكتبات (الرقم، العنوان، المحور، عدد المواد، المصدر).
- `index.html`: قارئ المكتبة، يعمل على GitHub Pages.
- `skills/`: مهارات Claude المرتبطة بالمكتبات ومنهج العمل.

## استخراج مادة

```bash
awk '/^##### المادة 304$/{p=1;print;next} /^##### /{p=0} p' land/011.md
```

## تنبيه

النصوص مستخرجة آليا. الملفات المعلمة `ocr: true` قد تتضمن أخطاء في الحروف. ملف PDF الرسمي هو المرجع عند الاستشهاد أمام المحاكم.

لا يوضع في هذا المستودع أي ملف أو معطى يخص موكلا.
